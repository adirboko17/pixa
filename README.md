# PhotosPro – דשבורד תמונות מוצר ברקע לבן

מערכת לעיבוד **תמונות מוצר** עם המודל החדש של OpenAI (`gpt-image-2`, אפריל 2026).
מעלים תמונות (גם בכמויות), המערכת מסירה את הרקע, מעמידה את המוצר על **רקע לבן נקי ומקצועי**, בגודל **1:1 (1024×1024)**, מוכן ל-Shopify, אמזון, אתרי מסחר וכו'.

## תכונות

- דשבורד בעברית עם תמיכה מלאה ב-RTL
- גרירה (drag & drop) של עשרות תמונות בבת אחת
- עיבוד מקבילי (1–8 בקשות במקביל) לזריזות
- סטטוס חי לכל תמונה: בתור / מעבד / מוכן / שגיאה
- הורדה בודדת או הורדה של **הכל כ-ZIP**
- כפתור "נסה שוב" לכל תמונה שנכשלה
- הגדרות מתקדמות: איכות, גודל פלט, פרומפט מותאם

## דרישות

- Node.js 18.18+ או 20+ (מומלץ 20)
- מפתח OpenAI עם גישה ל-`gpt-image-2`
  - חשוב: לחשבונות חדשים יש צורך באימות הארגון ב-OpenAI כדי להשתמש בדגם הזה.
    אם מקבלים שגיאה דמוית "must be verified" – לכו ל-Settings → Organization → Verify Organization.

## התקנה והרצה

```bash
# 1. התקנת תלויות
npm install

# 2. הגדרת המפתח
copy .env.example .env.local      # ב-Windows
# או
cp .env.example .env.local         # ב-macOS/Linux

# פתחו את .env.local והכניסו את המפתח שלכם:
# OPENAI_API_KEY=sk-...

# 3. הרצה במצב פיתוח
npm run dev

# 4. (פרודקשן)
npm run build
npm run start
```

לאחר ההרצה פתחו דפדפן בכתובת: <http://localhost:3000>

## איך זה עובד

הקליינט שולח כל תמונה ל-`/api/process` (נקודת קצה ב-Next.js).
הנקודה הזו קוראת ל-`openai.images.edit` עם הפרמטרים:

- `model: "gpt-image-2"` (המודל החדש מאפריל 2026)
- `image: <התמונה שהעלית>`
- `prompt: <פרומפט מקצועי לרקע לבן>` (אפשר לדרוס בהגדרות מתקדמות)
- `size: 1024x1024` (1:1 כברירת מחדל)
- `quality: high`
- `background: opaque`

התוצאה מוחזרת כ-PNG בקידוד base64, עוברת פוסט-פרוססינג שכופה רקע לבן `#FFFFFF` טהור, ומוצגת בדשבורד.

### למה gpt-image-2?

- **הוראות-עוקב משופר משמעותית** – חשוב במיוחד למצב הקבוצתי (סידור כמה פריטים ביחד)
- **שמירת זהות מוצר אוטומטית ב-high-fidelity** – פרטי המוצר, לוגואים, טקסט, צבעים נשמרים יותר טוב
- **טקסט מדויק יותר** – אם יש כיתוב על המוצר
- **גדלים גמישים יותר** עד 4K (אנחנו עדיין משתמשים ב-1024×1024 לעיבוד מהיר)

## עצות לתוצאות הכי טובות

- העלו תמונות מקור בחדות סבירה (לפחות 800px לצד).
- מומלץ שהמוצר יהיה ממורכז וברור גם בתמונת המקור.
- לאיכות מרבית – השאירו "איכות" על "גבוהה" (קצת יותר יקר ואיטי, אבל מקצועי).
- אם יש לכם סגנון רצוי (לדוגמה צל מסוים, מרווח גדול יותר) – כתבו אותו ב"פרומפט מותאם".

## עלויות

תמחור `gpt-image-2` (USD לתמונה, ריבועי 1024×1024):

| איכות | מחיר משוער |
| --- | --- |
| `low` | ~$0.006 |
| `medium` | ~$0.053 |
| `high` | ~$0.211 |

לגדלים לא-ריבועיים (1024×1536 / 1536×1024) המחיר מעט נמוך יותר.
המערכת מציגה אומדן חי לפני העיבוד וגם את העלות הסופית האמיתית אחרי כל תמונה.

## פתרון בעיות

- **"OPENAI_API_KEY חסר"** → ודאו שיש לכם קובץ `.env.local` עם המפתח, ושהרצתם מחדש `npm run dev`.
- **"Your organization must be verified..."** → אמתו את הארגון בלוח הבקרה של OpenAI.
- **שגיאות timeout** → הקטינו את "מקבילות" ל-2 או 1.
- **תמונה כבדה מדי** → המקסימום הוא 20MB לקובץ.
